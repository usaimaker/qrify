# QRify — Free QR Code Generator with Logo, Color & SVG

**Live:** https://qrify.dynv6.net

A free, 100% client-side QR code generator. No sign-up, no watermark, no upload — everything is rendered locally in your browser and your data never leaves your device.

## Features

- **No signup required** — starts instantly
- **No watermark** — clean output every time
- **Privacy-first** — nothing leaves your browser
- **Custom colors & gradients** — foreground/background customization
- **Multiple dot styles** — rounded, dots, square, extra-rounded, classy, terminal
- **Center logo support** — with automatic error-correction level H
- **Transparent backgrounds** — place a code directly onto artwork
- **Export formats** — high-res PNG or true vector SVG
- **Ready templates** — WiFi, vCard, URL, email, phone, WhatsApp, Maps
