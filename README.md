# QRify

Free QR Code Generator with Logo, Color & SVG — 100% client-side.

## Features

- **No signup required** — starts instantly
- **No watermark** — clean output every time  
- **Privacy-first** — nothing leaves your browser
- **Custom colors & gradients** — foreground/background customization
- **Multiple dot styles** — rounded, dots, square, extra-rounded
- **Center logo support** — with adjustable size and error correction
- **Export formats** — high-res PNG or true vector SVG
- **Ready templates** — WiFi, vCard, plain URL, SVG workflows
